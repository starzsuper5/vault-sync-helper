# Vault Sync Helper

A small mobile-compatible Obsidian helper that syncs selected Markdown notes with a paired remote notes service.

## Install with BRAT

1. Install and enable **BRAT** from Obsidian Community Plugins.
2. In BRAT, choose **Add Beta Plugin**.
3. Add this repository.
4. Enable **Vault Sync Helper** under Community Plugins.
5. In your web portal, open **Notes Sync** and create a one-time pairing code.
6. In Obsidian, open **Settings → Vault Sync Helper**, enter the portal address and pairing code, then tap **Connect**.

Pairing codes expire after 10 minutes and can only be used once. The helper only syncs notes explicitly provided by the paired service. Other vault folders are ignored.
